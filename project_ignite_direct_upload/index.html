Explore a scripted example of how an AI engineering teammate could reason about a quality concern. This demo does not connect to a repository, execute code or call a live AI service.

✳ Ignite engineering teammateSample mode
What should we test for a transfer timeout after debit?
I would investigate whether the debit was committed before the response timed out. The key risk is a customer retry creating a duplicate transfer or an unclear transaction state.
Suggested checks
1. Retry with the same idempotency key.
2. Confirm the ledger contains one debit.
3. Verify status and customer notification.
4. Reconcile pending transactions.
